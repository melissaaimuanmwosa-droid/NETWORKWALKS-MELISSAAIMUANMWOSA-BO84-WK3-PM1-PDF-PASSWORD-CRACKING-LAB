# PDF Password Cracking Lab – Network Walks

## Introduction

This project was carried out as part of my Network Walks cybersecurity training.

The practical involved using Network Walks tools and John the Ripper to recover passwords from three password-protected PDF files.

The main aim was to understand how password hashes work and how different tools can be used during password recovery.

## Objectives

- Understand how password hashes work.
- Learn how to use the Network Walks Hash Calculator.
- Practise using the Network Walks Password Cracker.
- Get familiar with John the Ripper.
- Recover passwords from three protected PDF files.
- Understand the importance of strong passwords.

## Tools Used

- Kali Linux
- Network Walks Hash Calculator
- Network Walks Password Cracker
- John the Ripper

## Practical Activities

### 1. Environment Setup

I prepared my Kali Linux environment and made sure the necessary tools were available for the practical.

### 2. Hash Calculation

I used the Network Walks Hash Calculator to work with the password hashes needed for the exercise.

### 3. Password Cracking

I used the Network Walks Password Cracker and John the Ripper to work on recovering the passwords of the PDF files.

### 4. Password Recovery

I carried out the exercise on three password-protected PDF files and successfully recovered all three passwords.
